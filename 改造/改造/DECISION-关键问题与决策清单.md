### 2.1 收益分配规则

#### ❓ 问题 9：归因算法选择

**需要确认**：

当多个达人使用同一关键词时，如何分配收益：

**方案 A：按作品数量平均分配**
```
达人 A 发布了 5 个作品
达人 B 发布了 3 个作品
达人 C 发布了 2 个作品

总收益 5000 元：
达人 A = 5000 × (5 / 10) = 2500 元
达人 B = 5000 × (3 / 10) = 1500 元
达人 C = 5000 × (2 / 10) = 1000 元
```
优点：简单、透明  
缺点：不鼓励优质内容

---

**方案 B：按作品质量加权分配（推荐）**
```
达人 A 发布了 5 个作品，总质量分 2500
达人 B 发布了 3 个作品，总质量分 1800
达人 C 发布了 2 个作品，总质量分 700

总收益 5000 元：
达人 A = 5000 × (2500 / 5000) = 2500 元
达人 B = 5000 × (1800 / 5000) = 1800 元
达人 C = 5000 × (700 / 5000) = 700 元
```
优点：更公平，鼓励优质内容  
缺点：需要采集质量数据

---

**方案 C：人工指定分配**
```
管理员手动指定每个达人的收益
```
优点：灵活性最高  
缺点：工作量大，不可扩展

---

**请选择**：
- [ ] 方案 A（简单模式）
- [ ] 方案 B（质量加权，推荐）
- [ ] 方案 C（人工分配）
- [ ] 混合模式：平时用 A/B，特殊情况用 C

---

#### ❓ 问题 10：质量分数计算公式（如果选择方案 B）

作品质量分数的计算权重：

```typescript
质量分 = 浏览量 × W1 + 点赞数 × W2 + 转发数 × W3 + 评论数 × W4
```

- W1（浏览量）= 0.5
- W2（点赞数）= 2.0
- W3（转发数）= 5.0
- W4（评论数）= 3.0

**理由**：转发和评论的转化价值更高

## 四、人工流程确认

### 4.1 日常运营流程

#### 流程 1：每日数据处理

**建议流程**：
```
1. 早上收到知乎邮件（约 8 点）
2. 管理员下载附件
3. 登录系统，上传文件
4. 系统自动解析和验证（1 分钟）
5. 管理员预览数据，确认导入（2 分钟）
6. 系统自动归因（5-10 分钟）
7. 管理员审核低置信度任务（10-30 分钟）
8. 批准归因结果，生成收益
9. 达人可在系统内查看收益
```

**预计每日工作量**：15-45 分钟

**是否接受**？
- [ ] 接受
- [ ] 需要调整流程：__________

---

#### 流程 2：作品审核

**建议流程**：
```
1. 达人提交作品登记
2. 作品进入"待审核"状态
3. 管理员定期审核（每天或每周）
4. 批准 → 作品参与归因
5. 拒绝 → 作品不参与归因，并通知达人原因
```

**审核频率**：
- [ ] 每天审核一次
- [ ] 每周审核一次
- [ ] 实时审核（达人提交后立即审核）
- [ ] 自动通过 + 抽查（每周抽查 10%）

推荐：**自动通过 + 抽查**，理由：
- ✅ 减少管理负担
- ✅ 抽查可发现问题
- ✅ 达人体验好

| 关键词绑定 | 用户声明使用某个关键词的行为 |
| 作品登记 | 达人在系统内记录已发布作品的行为 |
| 归因 | 将关键词级汇总收益拆分到具体达人的过程 |
| 质量分数 | 根据作品数据计算的综合评分 |
| 置信度 | 归因结果可靠性的评估指标（0-100%） |
| 未归因池 | 暂时无法分配的收益暂存区 |
