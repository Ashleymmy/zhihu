## 🔑 核心变更

### 变更 1：明确双层架构

**之前**：
```
归因引擎直接计算最终收益（包含团长抽成）
```

**现在**：
```
第 1 层：归因引擎 → 计算"归因收益"（基于作品贡献）
第 2 层：定价规则 → 计算"最终入账"（基于 pricing_rules）
```

### 变更 2：概念映射

| 新概念 | 说明 | 对应字段 |
|-------|------|---------|
| **归因收益** | 归因引擎的输出 | `attribution_results.allocated_revenue` |
| **来源金额** | 定价规则的输入 | `settlement_items.source_amount` |
| **达人应得** | 定价规则的输出 | 应用 percentage 或 fixed 后的金额 |
| **最终入账** | 扣除团长抽成后 | `earnings.amount` |

### 变更 3：复用现有表

**不需要新增**定价相关的表，完全复用：
- ✅ `pricing_rules` - 定价规则
- ✅ `settlement_batches` - 结算批次
- ✅ `settlement_items` - 结算明细
- ✅ `relay_logs` - 计算日志
- ✅ `earnings` - 收益记录

**只需新增**归因相关的表：
- ✅ `attribution_tasks` - 归因任务
- ✅ `attribution_results` - 归因结果
- ✅ `keyword_bindings` - 关键词绑定
- ✅ `creator_works` - 作品登记

## 🎯 优势

### 1. 复用现有体系

✅ **无需重复造轮子**
- 完全复用 `pricing_rules` 表和逻辑
- 复用 `settlement_batches` 批次管理
- 复用 `relay_logs` 审计日志

✅ **统一的定价管理**
- 管理员只需在一个地方配置定价规则
- 定价规则的修改自动应用到归因结果
- 历史数据可追溯

### 2. 灵活的业务规则

✅ **支持多种定价方式**
- 固定单价（fixed）：每个转化固定金额
- 百分比（percentage）：按归因收益的比例
- 按用户定制（target_user_id）
- 按角色统一（target_role）

✅ **自动化处理**
- 邮件数据导入 → 归因 → 结算批次 → 应用定价 → 生成收益
- 全流程自动化

### 3. 可审计与可追溯

✅ **完整的审计链路**
```
邮件数据 → attribution_tasks
         ↓
归因计算 → attribution_results
         ↓
结算批次 → settlement_batches + settlement_items
         ↓
定价规则 → pricing_rules（命中规则）
         ↓
计算日志 → relay_logs（详细记录）
         ↓
最终入账 → earnings
```

## 📊 完整示例

### 输入数据

**邮件数据**：
```
关键词: 知乎推广工具
收益: 5000 元
```

**作品数据**：
```
达人 A: 5 个作品，质量分 2500
达人 B: 3 个作品，质量分 1500
达人 C: 2 个作品，质量分 1000
```

**定价规则**：
```
达人规则: percentage = 0.6（60%）
团长规则: percentage = 0.1（10%）
```

### 计算过程

**第 1 层：归因引擎**
```
达人 A 归因收益 = 5000 × (2500/5000) = 2500 元
达人 B 归因收益 = 5000 × (1500/5000) = 1500 元
达人 C 归因收益 = 5000 × (1000/5000) = 1000 元
```

**第 2 层：定价规则**
```
达人 A:
  应得 = 2500 × 0.6 = 1500 元
  团长抽成 = 1500 × 0.1 = 150 元
  最终 = 1350 元

达人 B:
  应得 = 1500 × 0.6 = 900 元
  团长抽成 = 900 × 0.1 = 90 元
  最终 = 810 元

达人 C（无团长）:
  应得 = 1000 × 0.6 = 600 元
  最终 = 600 元
```

### 结果

| 用户 | 归因收益 | 应得 | 抽成 | 最终 |
|-----|---------|-----|------|------|
| 达人 A | 2500元 | 1500元 | -150元 | 1350元 |
| 达人 B | 1500元 | 900元 | -90元 | 810元 |
| 达人 C | 1000元 | 600元 | 0元 | 600元 |
| 团长 X | - | - | +240元 | 240元 |
| **合计** | **5000元** | **3000元** | - | **3000元** |

**验证**：
- ✅ 归因收益总额 = 5000 元（与邮件一致）
- ✅ 最终入账总额 = 3000 元（定价规则 60% + 团长抽成）
