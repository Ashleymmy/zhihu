# 网站关键词创建与邀请链接

本次仅修改网站，微信小程序仍使用原数据源。

## 关键词归属

- 达人可在有权限的项目创建关键词。独立达人自动绑定本人；团队达人自动记录当前团长与本人。
- `parent_id` 指向管理员、开发者或运营时表示平台管理关系，不生成团长佣金链路。
- 团长创建的词自动保留给本人，随后可分给本团达人或选择本人使用。
- 管理角色创建的词仍进入公共词库，保留 30 分钟团长优先领取规则。
- 全代理词库的关键词唯一约束、事务锁和幂等请求继续生效，旧计划也参与重名校验。一个词同一时刻只能有一条未释放的绑定。
- 已使用的词不能重新分配或释放；未使用且没有来源事实的词仍须审核退回。停止使用不删除历史归属或收益。
- 上游创建回执与本地联测均保留自建词的绑定，不将其重新放回公共词库。知乎创建成功不代表审核通过。

## 邀请链接

管理员、开发者、运营和团长可在 `/app/invitations` 管理自己创建的邀请链接，财务专职账号与达人没有管理权限。

- 新增：名称、有效天数（1–30）、注册人数上限（1–1000）。
- 编辑：名称、人数上限、有效期、启用状态。不能改变邀请创建人或所属团长，不能将上限调低到已注册人数以下。
- 复制：支持重新打开页面后复制。HTTP 环境不能调用剪贴板时，显示并选中链接供手动复制。
- 重新生成：显式废止原 token 并产生新链接，保留人数、有效期与已注册成员。
- 删除：软删除并立即禁止新注册；保留邀请来源记录和已注册成员归属。

分享地址形如 `/app/register#invite=<opaque-token>`。注册页面自动读取并校验，不显示邀请码字段，不要求填写邀请码。团长链接创建团队达人；管理角色链接创建平台管理的独立达人。服务端在同一事务里锁定邀请、创建达人、记录来源并扣减名额，客户端不能指定角色或上级。团长可在成员编辑中给直属达人分配自己已加入的有效项目；运营、管理员和开发者可为其有权管理的业务成员分配项目。独立达人由平台管理，达人侧显示邀请来源，不把运营邀请误当成团长团队归属。

## 数据兼容

新增扩展迁移 `005_invitation_links.sql`，只给 `member_invitations` 添加 `token_cipher` 和 `deleted_at` 两列。旧链接保持有效，不主动换号或修改成员。

新 token 继续以 SHA-256 摘要查找，另用 AES-256-GCM 保存供创建人再次复制的密文；密钥由 JWT_SECRET 经带专用用途标识的 HKDF 派生。列表与审计不返回 token 或密文，获取链接接口禁止缓存。若轮换 JWT_SECRET，旧链接仍可用，但再次复制需在页面显式重新生成。历史仅有摘要的链接同样需显式重新生成后才能再次复制。
