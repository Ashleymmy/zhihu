# 推广计划修复同步说明（2026-08-13 更新）

## 根因结论

真实 token、渠道和推广任务均已读取成功；计划“知乎故事”同步失败是知乎接口明确返回的业务错误：`HTTP 400 / code 400402`，关键词不符合知乎词根规则。问题不是 token 未加载、渠道过期或任务错绑。

## 本次修复

### 1. 安全、可操作的知乎错误诊断

文件：`server/src/zhihu/client.ts`、`server/src/services/plans.service.ts`

- `400402` 统一显示“关键词不符合知乎规则，请更换关键词”；不再把知乎原始 message、请求参数或可能包含敏感信息的内容写入 `sync_error`。
- 未知上游错误只保留 HTTP 状态和经过校验的数字错误码；普通网络错误统一为通用文案。
- HTTP 200 携带 `error` envelope 仍会按失败处理。
- 前端列表/详情只收到白名单化的 `syncError`。

### 2. 失败计划关键词修改与重试边界

文件：`server/src/routes/plans.ts`、`server/src/services/plans.service.ts`

- 创建、检查、编辑关键词均拒绝空格、逗号、顿号和分号等分隔符，只允许单个关键词。
- 只有 `sync_status='failed'` 且尚无 `zhihu_plan_id` 的计划可以修改关键词；已成功同步的计划不能改关键词。
- 修改时在事务内锁定计划并再次校验状态，检查同渠道重复关键词；修改成功后清空旧错误并重新入队。
- 词根错误计划不能继续盲目重试旧关键词，必须先换新关键词。
- 队列任务 ID 同时绑定计划 ID 和关键词指纹，关键词变化不会被旧任务去重吞掉。

### 3. 同步任务竞态保护

文件：`server/src/jobs/pushPlan.ts`

- 任务开始时只允许抢占当前关键词仍为 `local/failed` 的计划。
- 成功或失败落库均要求计划 ID、当前关键词和 `syncing` 状态同时匹配，旧任务不能覆盖新关键词或已完成的结果。
- 知乎 payload 继续只发送 `task_id`、`channel_id`、`content_url`、`popularize_type`、`keyword`，有值时才发送 `second_channel_id`。

### 4. 前端反馈与交互

文件：`platform/src/types/api.ts`、`platform/src/utils/format.ts`、`platform/src/views/dashboard/CampaignsView.vue`

- 同步状态补齐 `syncing`，失败徽标可查看安全错误原因。
- 词根错误计划隐藏“盲目重试”按钮，编辑窗口提示必须更换关键词；普通失败仍可重试。
- 创建/修改表单增加单关键词校验和知乎词根规则提示。
- 保留已有“同步渠道及任务”、推广作品渠道字段修复及用户未提交改动。

### 5. 推广作品创建页渠道校验（既有修复）

文件：`platform/src/views/dashboard/ZhihuCompositionsView.vue`

渠道下拉框和表单校验字段均使用 `channel_id`，避免已选渠道仍提示“请选择渠道”。
