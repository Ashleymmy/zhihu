## 一、项目目标与范围

### 目标

交付一个 Web 端管理平台，让运营同学无需写代码即可完成知乎知星河推广的日常操作。

### 范围内（In Scope）

| 项 | 说明 |
| --- | --- |
| 27 个接口的 UI 化 | 31 个接口中排除 4 个即将下线的 v1 接口 |
| 接口调试台 | 展示原始请求/返回，供开发联调 |
| 批量操作 | Excel 上传 + 异步任务轮询 + 结果下载 |
| 数据展示 | 实时报表、内容榜单浏览 |
| 举报流程 | 截图上传 + 提交 + 状态查询 |

### 范围外（Out of Scope）

| 项 | 原因 |
| --- | --- |
| 微信小程序 | `app/` 目录，本轮不做，但服务层设计要为其复用留口 |
| BFF 后端实现 | 需单独立项。**但生产上线前必须完成**，见风险 R01 |
| 数据可视化图表 | 一期先出表格，图表看需求再定 |
| 多用户权限体系 | 一期单用户，权限由 BFF 层负责 |
| 数据落库与历史归档 | 一期直连知乎接口，不做本地存储 |

### 关键约束

| 约束 | 影响 |
| --- | --- |
| v1 接口 **2026-08-25** 下线 | 只做 v2，无迁移工作量 |
| 接口有日配额 | 测试用 Mock，联调手动逐个执行 |
| `secret_key` 不能进前端 | 生产必须有 BFF，见风险 R01 |
| Excel 模板未拿到 | 阻塞批量功能的完整验收，见阻塞项 D01 |
