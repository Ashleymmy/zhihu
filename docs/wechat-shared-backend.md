# 网站与微信小程序共享后端

## 数据与账号

网站和小程序都通过 ECS 的业务服务访问同一个 MySQL。微信云环境仅部署事件函数 `opc-bridge`，不开放数据库公网连接，也不使用知乎作为中继。旧小程序账号和业务库是测试数据，不迁入真实库。

首次微信登录，已有网站账号验证账号密码后绑定；新用户填写手机号、密码、邀请码注册网站账号并绑定当前微信。一微信对应一个网站账号，一个网站账号对应该小程序的一个微信；发生冲突必须由管理员核实处理。此版本不提供自动覆盖绑定。

可选的小程序注册短信验证默认关闭。开启后新注册必须提供有效短信验证码；历史账号、网站录入号码及密码绑定微信不自动成为手机号已验证。代码、配置和启用顺序见 [小程序注册短信验证](mini-sms-registration.md)。

小程序拥有独立 `mini` 会话，不占网站 `web` 和移动浏览器 `mobile` 会话。角色、项目成员、停用与会话撤销继续由网站服务控制。无项目的新用户可查看邀请与归属，需团长/运营在成员编辑中分配其有权分配的项目。

## 邀请与业务归属

小程序保留 8 位可见邀请码和注册预填分享路径。邀请码关联网站 `member_invitations`，与网站邀请链接共用有效期、容量、停用和使用记录。邀请码不产生奖金，不生成收入流水，也不进入可提现余额。

团长邀请加入自己的团队；团队达人邀请加入当前所属团长团队；独立达人及平台管理者邀请按独立达人归属，邀请来源另行记录。已注册账号不能通过再次填写邀请码改归属。团长关系变化后旧的团队邀请码失效，邀请页重新生成符合当前关系的邀请码。

关键词、单价、作品、报表、收益、提现均使用现有网站权限和业务规则。小程序作品登记一次事务写入网站作品和平台核验记录，再使用现有队列提交知乎；平台核验与知乎审核分别显示。重试保留请求凭据，避免因响应丢失重复登记。Excel 使用网站解析器，小程序按所选关键词预览并提交；跨关键词表格通过网站批量登记。

小程序旧云后端的角色统一价、邀请奖金、关键词自动重试配置不迁入；定价使用网站现有的成员单价。财务确认核对整个所选期间的快照，开放提现核对项目当前待开放总额，不沿用旧云库的分片编号。

## 学院课程

学院的公共入门课程存放在 ECS MySQL 的 `college_courses`，不依赖项目成员资格。`007_college_courses.sql` 一次性导入原小程序的 7 门入门课程及正文；旧种子中填写的学习人数为示例数，不作为真实统计展示。读接口只返回已上架记录，下架或删除后不会在读取或重启时重新生成课程。

网站原有 `project_courses` 继续按项目权限显示为单独分组；退出或停用项目后无法读取其课程详情。公共课程与项目课程均通过 `opc-bridge` 的 `/modules/zhihu/courses` 列表与详情接口读取。没有课程时展示空状态，接口失败时保留错误与重试入口。课程上架字段为 `published`，正文为 `sections` JSON，目前尚无公共课程管理界面。

本地联调和上传须使用本分支的 `weixin-app`。旧工作目录调用的 `opc-api` 属于旧云库，不能用其显示结果替代共享后端验收。

## 安全与部署

`opc-bridge` 从微信执行上下文取得 APPID/OPENID，使用服务端环境变量 `WECHAT_BRIDGE_SECRET` 对原始请求体、时间戳及随机 nonce 签名。ECS 验证签名、60 秒时间窗口、APPID 和持久化防重放 nonce。用户传入的 OPENID、域名、客户端类型不作为身份依据。桥接仅请求固定 HTTPS 域名，不自动重试写操作。

ECS 环境增加 `WECHAT_APP_ID=wx22b91776ccf37354` 与不少于 32 字符的随机 `WECHAT_BRIDGE_SECRET`；相同密钥只配置在微信事件函数的环境变量里。不得放入小程序代码、Git 或日志。未配置时入口返回 503，网站原有路由继续工作。

迁移 `006_wechat_identity.sql` 为增量迁移；上线前备份数据库和环境文件。先发布 ECS，再单独发布 `cloudfunctions/opc-bridge`（Nodejs20.19，60 秒，256 MB，云端安装依赖），最后编译上传本目录小程序。不要批量部署原 `opc-api/opc-worker/opc-admin`。旧函数和测试库暂保留回滚；切换后关闭旧 worker 的定时触发，避免对知乎重复同步。

只上传/验收开发版不等于微信审核通过或正式发布。回滚应用镜像不删除新增数据表或回灌旧库。

## 验证

`npm --prefix weixin-app test` 验证当前页面和云桥；`npm --prefix weixin-app run build` 执行测试与微信 WXML/WXSS 编译。原云库用例保留在 `test:legacy-cloud`，它们依赖旧云函数打包产物，不作为共享后端发布入口。

服务端新增 `tests/attribution/wechat-shared.spec.ts`，使用独立 MySQL，验证签名防重放、共享账号、并行会话、邀请绑定与无奖金、项目授予、唯一关键词、作品+平台核验、私有上传和禁用账号。
