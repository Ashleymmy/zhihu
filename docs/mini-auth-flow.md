# 小程序账号流程（2026-10-03）

网站与小程序继续使用同一个平台账号库、手机号验证状态、角色、项目和邀请归属。小程序会话独立于网站 Web/移动浏览器会话。微信绑定只决定是否可使用微信快捷登录，不决定账号归属。

| 入口 | 验证方式 | 微信绑定行为 |
| --- | --- | --- |
| 账号密码登录 | 平台账号和密码 | 不新增、不改变绑定 |
| 短信登录 | 平台账号已验证的手机号和本次验证码 | 不新增、不改变绑定 |
| 注册 | 登录账号、密码；无需手机号或短信 | 不自动绑定 |
| 微信快捷登录 | 云函数提供的可信微信身份 | 已绑定则登录；未绑定提示先使用账号密码登录，之后在个人信息主动绑定 |
| 绑定账号 | 平台账号密码、账号登记手机号的短信验证码 | 用户主动绑定当前微信 |
| 个人信息 → 社交账号绑定 | 当前登录账号密码、手机验证码 | 只能绑定当前账号；已有绑定不覆盖 |

未勾选协议时按钮显示灰色，点击只展示协议确认窗口。取消不勾选、不请求登录；“我已确认并阅读”只勾选，用户再次点击主按钮才提交。密码登录、短信登录、微信登录、注册、绑定和手机号验证均使用相同原则。

邀请信息通过分享卡片的 `invite` 参数携带，不显示邀请码输入框。兼容旧 `code` 参数及携带同样邀请信息的 `scene` 参数；不缓存到永久存储。没有邀请信息时，注册为平台管理的独立达人；明确带来的邀请无效或撤销时必须提示失败，不能退化为无邀请注册。邀请仍使用网站的 member_invitations/member_invitation_uses，不新增奖励。当前提供微信分享卡片；二维码生成服务尚未新增。

短信有效期 5 分钟、发送间隔 60 秒、最多 5 次错误。注册、登录、手机验证、微信绑定分别校验验证码用途，并绑定可信微信客户端；账号相关验证码绑定账号、密码版本和手机号验证状态。消费验证码与手机号验证、绑定或会话签发放在同一事务。保留号码、客户端和全站发送额度。账号注册不依赖短信服务，创建时 phone 和 phone_verified_at 均为空；不得将未验证号码写成已绑定。兼容旧版手机号＋验证码注册协议，旧协议仍严格校验并消费验证码。

验证码 2.0 按本次决定暂不实现：没有安装微信插件、创建阿里云场景或新增收费服务。后续可在 `server/src/sms/registration.ts` 的统一 `sendCode` 入口、额度预占之前接入服务端验证，再在各页面共用的短信发送流程加入挑战结果。不得接受客户端自报“验证通过”或失败后绕过验证；本版仅使用现有短信限流。

## 人工验收

测试者自行发送到本人手机号；不要在日志、截图和缺陷记录中记录验证码、密码或完整手机号。

1. 首次进入登录页默认密码登录；只有一个切换入口。切换短信模式后能切回；旧密码或旧验证码被清除。
2. 在登录、注册、绑定页面未勾选协议直接点主按钮：显示确认窗口，未发送登录/注册请求。取消后仍灰色；确认后自动勾选并恢复绿色，尚未自动提交。协议链接能打开完整原文。
3. 用新登录账号、不经邀请入口注册：无需手机号或验证码；成功后为独立达人，个人信息显示登录账号、手机号未绑定、微信未绑定，Web 可用同一账号密码登录。账号为 3–32 位，字母开头，可用字母、数字、下划线和短横线。
4. 从团长分享卡片进入：没有邀请码输入框；完成注册后双方看到同一邀请/团队归属。先去登录页再返回注册，邀请信息仍保留。失效邀请应报错。
5. 普通密码或短信登录后查看“社交账号绑定”：不自动绑定微信。已有绑定的老账号仍保留绑定。
6. 未绑定微信点击微信登录：停留在账号密码登录，提示登录后从个人信息绑定；不强迫验证手机。已有绑定照常快捷登录。个人信息中的主动绑定仍需要密码和有效验证码，不允许覆盖他人绑定。
7. 从个人信息绑定：账号固定为当前登录账号；绑定成功后返回个人信息显示已绑定当前微信。退出后可微信快捷登录。尝试绑定已属于另一账号的微信或另一微信已绑定的账号应被拒绝。
8. 短信登录、验证手机、绑定微信的重发倒计时均为 60 秒；切后台后恢复按实际剩余时间倒计时。重复点击不会多发；跨用途验证码不可混用。
9. 已验证手机号但未绑定微信的账号可短信登录；未验证手机号需先密码登录后在个人信息验证。未验证号码不能直接短信登录。
10. 绑定或登录后核对 Web 和小程序的角色、团队、项目、作品归属一致；小程序登录不会挤掉现有 Web/移动浏览器会话。

部署要求：新后端先发布，随后上传新版小程序 2026.10.3.1。短信预算从全平台每天 10 条调整到 1,000 条，仍保留号码每日 5 次、微信客户端每日 10 次及 60 秒重发间隔。旧版手机号注册协议继续保留校验；新版注册策略为 registrationMode=account、smsRequired=false。既有账号、绑定和业务记录不迁移、不重建。回滚保留生产数据库，恢复上一应用镜像及原短信配置。
