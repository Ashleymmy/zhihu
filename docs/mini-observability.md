# 小程序监控与成员双端信息

实施顺序：服务器观测与成员信息 → Web 监控与筛选 → 权限/真库/页面验证 → 备份发布服务器 → 发布云桥观测元数据 → 上传小程序版本上报。

## 页面与权限

`/system/monitor` 保留原账号行为视图，新增小程序状态。开发者、完整管理员查看技术指标；运营管理员、运营职责管理员只查看业务概况。财务账号、团长、达人不能进入全局监控。团长仍在成员管理查看本人和本团成员的绑定与会话，沿用成员列表行级范围。

成员列表支持已绑定、未绑定、已绑定待分配项目、近期绑定冲突、已绑定需重新登录筛选。异常卡可跳转筛选或准确定位成员。已绑定不等于实名或手机号认证；未实现解绑、换绑、实名认证。会话有效不等于在线，停用账号不会计入有效登录账号数。

## 数据口径

- 双端共用 users 和业务库，不创建第二份账号库，不展示虚构的账号同步进度。
- 当前 AppID 的 wechat_identities 表示绑定；其他 AppID 的绑定不算当前小程序。
- login_sessions 按电脑浏览器、移动浏览器、小程序统计有效/过期/撤销状态。最近登录取该端会话签发时间，不用用户全局最后登录代替。
- 已绑定待分配项目：启用中的达人，已绑定当前小程序，但没有未退出且启用的项目。
- 近期绑定冲突：最近 7 天出现 40908 且在事件顺序上晚于该账号最近成功小程序登录。只在密码验证成功或微信绑定已确认后记录关联用户，不能由客户端自行指定。
- 公共课程展示总数与上架数，0 门仅提示核对上架安排，不自动生成课程。

## 观测边界

008 迁移增加 mini_request_events。仅观测通过签名、AppID、防重放校验并到达 ECS 的请求，统计最近 24 小时请求量、5xx 错误率、4xx 拒绝和业务处理耗时。没有请求显示暂无观测，不能据此宣称链路正常。云函数未执行、网络未到达 ECS、签名校验前失败需要结合微信云日志排查。

白名单接口类别、HTTP 状态、业务码、耗时、可信用户 ID 和版本元数据进入事件；不存请求/响应正文、密码、令牌、OpenID、手机号和任意 URL。异步缓冲有上限，记录失败不阻断业务；面板显示本次进程的丢弃量、记录维护失败和开始时间。时间使用数据库时间，异步记录通常延迟不超过 500 毫秒。事件保留 7 天，随新记录分批清理过期记录。

云环境及桥版本由云函数自身写入签名信封，客户端不能覆盖；客户端版本/环境属于上报信息，不代表微信审核与发布状态。旧客户端及旧云桥仍能请求，新字段缺失显示未上报。先部署兼容服务端，再部署云桥，最后上传小程序。
