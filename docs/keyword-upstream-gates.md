# 关键词失败处理与独占使用

2026-10-03 修正 Web、小程序共用的关键词操作规则。

- 创建只建立本地独占归属。知乎成功返回计划 ID 且计划可用后，才能分配、开始使用或登记作品。显式配置的隔离联测账号使用模拟状态。
- 可领取列表在服务端分页前排除现有绑定、任何历史使用标记、作品、证据、订单事实、收益记录；领取和分发事务再次检查，防止并发占用。
- 历史作品归属与当前执行人冲突时，禁止新增使用；保留全部原始记录，交由运营核对，不自动重绑。
- 知乎明确创建失败且没有官方计划 ID 的记录，创建人或当前绑定的团长/执行人（以及有操作权限的管理人员）可处理。未使用的记录可“编辑并重试”：只改关键词，保留任务、渠道、推广链接及绑定。提交后重新等待知乎结果。
- 已有作品或使用记录的失败词不可原地改名，可“沿用信息新建”。新词遵循正常创建规则；旧词与作品归属不变。
- “删除错误记录”将失败词归档、终止新增使用并从关键词列表移除，保留计划、绑定、作品、订单与审计。不是释放使用权，也不删除上游记录。
- 小程序“已完成”更名为“已停用”；新增“已登记作品”，表示有作品记录，不表示审核通过或已结算。关键词失败、作品提交失败优先显示，不能伪装成待审核。

## 手工复核

1. 创建一个知乎拒绝的词：两端都显示失败原因，不能分配或登记作品。
2. 对未使用的失败词点击“编辑并重试”：旧词预填，只改关键词即可；任务、渠道、链接与归属保留，成功前仍不可下发。
3. 删除失败词：确认提示保留历史，列表移除；已有作品仍能查到。
4. 同时用两个账号领取同一可领取词：只允许一个成功；另一端刷新后不可再领。
5. 检查“已登记作品”和“已停用”：前者能对应作品记录，后者不能新增使用。

## 自动验证

隔离 MySQL 回归覆盖创建、分配、登记/批量导入、历史记录保护、编辑权限与重试、归档、并发领取、模拟同步及微信接口。前端状态与操作单测、真实 Vue 组件交互及微信模拟器页面均已验证。线上核验只读业务关系，不登录真实账号或替换其会话。
