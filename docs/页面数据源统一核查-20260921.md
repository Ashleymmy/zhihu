# 页面数据源统一核查（2026-09-21）

已修复“登记作品”计划选择器不能输入搜索、只读取前 100 条及重复打开时使用旧缓存的问题。管理员、团长、达人共用搜索组件及分页读取逻辑，可按关键词、渠道、计划编号搜索，必须选择真实记录才能提交；加载中、加载失败或仅输入文字时禁止提交。

## 数据来源与处理范围

| 页面或流程 | 统一读取来源 | 本次处理 |
| --- | --- | --- |
| 推广计划、关键词与作品关联、登记作品、回传计划选择 | 后端 plans 及其关键词关联；后端继续执行账号可见范围 | 读取所有分页；每次打开重新加载；编号区分同名记录；稳定排序；失败提供重试 |
| 创建推广计划中的任务、渠道 | 官方同步后的 tasks、channels | 读取所有分页；移除下拉只展示前 8 条；重新打开刷新目录；修正计划更新请求方法 |
| 任务列表、产品库 | 同一 tasks 目录及官方原始元数据 | 完整分页；产品名从 rawJson 正确提取；筛选期间不混入旧请求结果 |
| 盐选榜单、有声书、漫剧、评论截流、风险举报 | 现有经过登记的知乎内容查询接口，经后端代理 | 完整 offset/limit 分页；检测不完整、重复或变化的分页；筛选和切换只展示最后一次请求 |
| 内容标签 | 现有知乎内容标签查询代理 | 核对既有来源，保留查询失败提示 |
| 素材库 | 本平台 story_items | 后端取消固定截断为 200 条，改为分页；共享接口完整读取 |
| 数据看板、数据分析、旧概览组件 | metrics/overview、metrics/trend | 在共享接口统一后端结构；缺少消耗数据时显示“—”；最近计划统计明确标注范围 |
| 收益、结算收益明细与系统收益导出 | earnings、earnings/summary | 完整分页；统一日期和归属字段；补齐关键词、渠道、负责人；汇总总额；趋势不再把不同年份同日合并 |
| 提现、申诉列表 | 现有审批服务及角色权限 | 完整分页；相同创建时间按编号稳定排序 |
| 回传配置 | callbacks/rules、callbacks/secret | 完整分页；管理员选择器可搜索；修正密钥展示字段；移除团长/达人没有后端写权限的空操作 |
| 关键词适用报价 | price-agreements | 完整读取报价版本，使用 versionId 区分同一协议下多个版本 |
| 历史邮件 / Excel 导入记录 | data-import/batches | 后端取消固定截断为 100 条，增加分页；共享接口完整读取 |
| 审计日志及导出 | core/audit-logs | 导出完整分页并保留用户名、日期、操作筛选 |
| 运营管理、报价、作品审核、数据待办、财务做账、钱包 | attribution-options、keywords、price-agreements、evidence、imports、workbench 等现有归因服务 | 核对既有来源与分页；运行归因、报表、权限、结算集成回归；财务门禁继续有效 |
| 工作台、模块、项目、人员、系统管理 | core 的项目、接入账号、用户、日志和设置服务 | 核对来源；团长不再显示或访问缺少 project.manage 权限的 MCN 入口 |
| 订单管理 | 尚无已接入的订单明细来源 | 移除把推广计划当成会员订单的展示，提供现有推广效果与收益入口 |
| 知识付费 | 尚无已接入的课程销售来源 | 移除写死的课程、销量、收入及只修改浏览器内存的增删改 |
| 创意工具 | 既有未开放功能说明 | 保留明确的未开放状态 |

“统一来源”按业务实体统一：官方目录/内容使用现有官方接入；本平台的作品登记、归属、报价、审批、结算和配置使用对应平台记录。平台记录不会被标成官方全量查询结果。

## 验证

- 全部前端工作区类型检查及单元测试通过；统一前端生产构建和后端构建通过。
- 共享接口测试 23 项通过，其中包含 205 条记录跨页、有效分页大小、短页、重复页、网络失败、报价多版本、真实统计结构和计划更新方法。
- 后端目录、同步、官方协议及导入路由测试 30 项通过。
- 归因及报表集成测试 71 项通过；平台核心测试 16 项通过、1 项按既有配置跳过。
- 隔离数据库浏览器巡检：管理员 39、团长 29、达人 28，共 96 次页面入口访问；没有页面脚本异常或 NaN / Invalid Date。团长访问旧 MCN 地址按权限回到工作台。
- 三端均验证：205 条计划的末页可搜索；同名词可区分；键盘选择；重新输入会清除旧编号；打开弹窗能看到新增的第 206 条；分页失败阻止提交并可重试；最终登记在隔离数据库中保存并回显。
- 收益页面用真实数据库样本验证了金额、关键词、渠道和负责人。
- 盐选、截流、风险、有声书、漫剧分别用 205 条代理响应样本验证完整显示。官方网络在隔离测试中被阻断，另验证了不可用响应；这些测试不代表生产授权或实时官方数据已经核验。

复现浏览器测试：先运行 `pnpm build`，再运行 `node server/tests/attribution-ui/data-sources.cjs`。需要 Docker、Edge 和 Playwright；若项目未安装 Playwright，可通过 `OPC_PLAYWRIGHT_MODULE` 指向已安装模块。测试生成独立数据库，只访问本机测试主机；巡检时重置测试主机的请求计数，生产限流没有改动。

本次核查产物在 `.opc-work/data-source-ui/report.json` 和同目录截图；命令日志使用 `.opc-work/data-source-*` 前缀。

## 外部限制与发布注意

现有项目没有可验证的知乎“历史计划列表查询”接入，不能证明本地计划库包含平台建立前的所有官方历史计划，也不能凭本地同步成功回执推断最新官方审核状态。现有能力说明继续保留，未猜测或新增官方接口。

订单明细与课程销售仍需真实数据接入才能开放。财务门禁及未配置接入账号的提示不是可用数据，测试未绕过生产业务门禁。

`data-import/batches` 与 `story-items` 现在返回 `{ list, total, page, pageSize }`，项目共享服务已同步适配。发布时须同时更新前后端。本次只修改和验证工作区，未部署生产环境。
