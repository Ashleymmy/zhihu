# 小程序提审前核对（2026-10-03）

适用版本：2026.10.3.2。本文记录真实功能与核对范围，不代表微信审核结果。

## 本次调整

- “我的”与“个人信息”提供帮助与隐私入口，游客可查看协议和联系邮箱。
- 注销须验证当前平台密码、勾选说明并再次确认，作用于网站和小程序共用账号。未结清款项、进行中业务、成员和项目移交等事项会阻止注销；最后一个开发者或无开发者时最后一个管理员不能直接注销。
- 注销事务清除账号资料、微信绑定和会话，撤销邀请，保留必要业务和财务证据及内部关联编号。注销不是可恢复的停用，数据库约束禁止将已注销账号重新激活。
- 小程序云函数对提交的可展示文字调用微信 `security.msgSecCheck` v2。密码、手机号、验证码、备用联系方式、收款字段和原始文件不作为检测文本。风险、待复核、接口故障均不放行。
- 云函数生成内容摘要并随可信身份签名，客户端不能自行声称检查通过。后端强制校验需启用 `MINI_CONTENT_SAFETY_REQUIRED=1`。
- 协议按芜湖云途文化传媒有限公司、双端共用账号、可选手机号验证和主动微信绑定重写。收益提示明确账单确认、款项到账并开放后才可申请提现。
- 删除首页未开放渠道入口和无实际操作的实名认证占位；现有业务和权限保持真实一致，不针对审核人员切换展示。

## 发布顺序

1. 备份数据库、当前版本与配置，发布能接收 `contentSafety` 的后端，先保持强制开关关闭。
2. 部署 `opc-bridge` 云函数，包含 `config.json` 的 `security.msgSecCheck` 权限。保留既有云环境及签名密钥。
3. 通过真实小程序身份核验内容检查后，设置 `MINI_CONTENT_SAFETY_REQUIRED=1` 并重建应用容器。核验缺少证明的文字写入被拒绝，不执行真实用户资料修改。
4. 上传并确认小程序 2026.10.3.2。体验版选定和最终提交由微信后台操作人完成。

旧云函数与新后端兼容；新云函数不能先于兼容后端部署。回退应用时必须同步考虑云函数的请求格式，不能仅回退后端而保留新请求。数据库新增列为增量迁移，不得为回退应用恢复旧业务数据库。

## 人工验收

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 游客帮助 | 未登录进入“我的 → 帮助与隐私” | 可查看协议、复制邮箱，不强制登录 |
| 登录注册 | 使用平台账号密码；手机号保持未验证 | 能进入平台；不自动绑定微信 |
| 内容提交 | 修改昵称或提交关键词；另测不合规文字 | 正常内容可提交，未通过内容有明确提示且不落库 |
| 可选资料 | 个人信息清空备用联系方式 | 保存后为空，其他资料不变 |
| 注销取消 | 用专用可丢弃测试账号输入密码，弹窗选取消 | 账号和会话均保留 |
| 注销阻碍 | 专用账号有未结款项或待移交成员 | 显示具体待办，不能直接注销 |
| 注销完成 | 无阻碍的专用账号确认注销 | 网站及小程序均退出；原凭据不可登录；微信绑定解除 |
| 收益说明 | 查看首页、收益页和提现流程 | 不承诺报表确认即自动可提现，与到账开放规则一致 |

注销、作品提交和提现测试只能使用经授权的专用测试账号及明确标识的测试数据，不操作正常用户账号。自动化数据库测试使用独立 MySQL；不向真实手机号发送短信。

## 提交前仍需运营核实

- 微信后台已通过的服务类目和资质必须覆盖实际项目协作、作品登记、报酬结算及团队管理功能。应对照《运营规范》5.3、5.9等条款审查实际商业模式，不以改名称代替判断。
- 审核需要登录时，提供能访问相关功能的专用测试账号；按需要分别覆盖达人、团长、运营等身份。不要提交生产开发者/管理员凭据，不给审核账号特殊越权逻辑。
- 微信后台隐私保护指引与当前实际使用的数据项一致。运营方确认联系邮箱可收信，并落实协议中的回复期限。
- 微信未发布小程序的文字检测日额度按当前官方文档为 100 次；上线前关注额度和失败情况，不能因额度不足改为默认放行。
- 本次自动检测覆盖小程序提交的文字，不覆盖历史内容、从网站录入的文字或图片/视频。运营仍须审查已有及跨端展示内容，处理投诉；后续增加媒体上传时应补充对应检测能力。
- 备份应限制访问并按保留策略轮换；离线备份不是同步擦除。灾难恢复前保留并重放已注销用户清单及清理操作，防止恢复旧备份使账号和个人资料重新生效。
