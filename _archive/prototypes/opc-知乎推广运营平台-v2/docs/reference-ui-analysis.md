# 参考原型视觉观察

参考站点：`https://opcuiredesig-ev8nkxwt.manus.space`

## 已观察页面

### 首页

- 使用暖白画布、极浅灰侧栏和细灰分隔线，整体无渐变、无玻璃化、阴影极少。
- 左侧为窄栏主导航：品牌标识、四个简短入口和底部账户信息；当前入口以浅色块标记。
- 顶栏极薄，包含页面序号、搜索、通知与深色主操作。
- 主标题使用大号高对比衬线字，辅以小号等宽/大写式的序号和路径标签；橙色仅用于微小的状态或标记。
- 页面主体采用“运行指标 → 任务队列 → 风险摘要 → 活动”的明确工作流，而不是高装饰性卡片堆叠。

### 任务页

- 信息布局为左侧任务队列与右侧任务档案的双栏工作台，表格以细线划分行而非厚重卡片。
- 状态筛选为紧凑的文本分段控件；搜索和筛选入口位于列表顶部。
- 选中任务以细橙色标记点强调，状态文字使用低饱和色，不使用大面积彩色背景。
- 任务档案采用无边框或细分隔线的表单字段，主按钮为深色实底，强调一次明确操作。

### 团队与设置页

- 团队页延续“左侧队列、右侧详情、底部协作摘要”的工作台结构，成员行以细线和简短负载进度表示，头像为深色方形缩写。
- 设置页采用带编号的纵向配置段落；每个段落左侧是短标题，右侧为字段、开关或状态信息，以横向细线分隔。
- 输入框是无圆角或极小圆角的白色表面，橙色只用于焦点/标签提示；主要保存动作使用炭黑实底按钮。

## 可迁移原则

1. 采用暖白/石灰/炭黑的低饱和基调，橙色只作为状态与编号强调。
2. 保留侧栏和顶部工作流，但降低圆角、阴影、蓝色面积与图标底色。
3. 用序号、细线、表格行和双栏详情取代大面积“英雄卡”与装饰性分屏。
4. 保留当前产品的推广、词条、回传、知乎工作台等信息架构与权限控制。
5. 对配置型页面使用编号分段和细线字段，而不使用彩色表单卡片。
