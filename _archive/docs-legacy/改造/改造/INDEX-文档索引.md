## 🎓 核心概念速查

### 双层架构

```
第 1 层：归因引擎
  输入：关键词汇总收益（邮件数据）
  输出：每个达人的"归因收益"
  
第 2 层：定价规则（现有 pricing_rules）
  输入：达人的"归因收益"
  输出：达人应得 + 团长抽成
```

详见：[整合方案](./SOLUTION-归因引擎与定价策略整合方案.md#二归因引擎与定价规则的协作)

---

### P0 模块清单

| 模块 | 工作量 | 说明 |
|-----|-------|------|
| 0-1 数据库表 | 0.5 天 | 4 张核心表 |
| 0-2 邮件导入 | 2 天 | 手动上传 CSV/Excel |
| 0-3 关键词绑定 | 1.5 天 | 达人声明使用关键词 |
| 0-4 作品登记 | 2 天 | 达人登记作品和质量数据 |
| 0-5 归因引擎 | 3 天 | 核心算法 + 对接定价 |
| **合计** | **9 天** | 核心链路完成 |

详见：[渐进式开发计划](./PLAN-渐进式开发计划.md#p0-模块核心链路必须)

### P0 简化原则

**做**：
- ✅ 核心业务链路

- ✅ 复用现有定价体系

**不做**（P1/P2）：

- ❌ 去重检测
- ❌ 作品审核

- ❌ 人工调整
