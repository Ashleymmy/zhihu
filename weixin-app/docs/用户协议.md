# TIMO 多渠道 OPC 业务平台用户协议

更新与生效日期：2026-09-30

## 一、总则

1. 本协议是你（以下称「用户」）与 TIMO 多渠道 OPC 业务平台运营方（以下称「平台」）之间就使用本平台服务所订立的协议。
2. 你在注册或使用本平台前，应认真阅读并充分理解本协议全部内容。你完成注册或实际使用本平台服务，即表示你已同意本协议的全部约定。
3. 平台有权根据业务调整更新本协议，更新后将在小程序内公示。你不同意变更内容的，可停止使用并联系平台注销账号。

## 二、服务内容

本平台为用户提供：推广任务（关键词）的领取与分发、作品提交与审核、收益结算与提现、邀请好友与团队管理、培训课程等服务。平台可根据运营需要调整服务内容并提前公示。

## 三、账号注册与管理

1. 你应使用本人真实有效的手机号注册，注册时需填写有效邀请码；注册成功后系统自动分配账号并确定团队归属。
2. 你应妥善保管账号与密码，不得出借、出租、转让账号。因你主动泄露导致的损失由你自行承担。
3. 同一手机号、同一微信仅能绑定一个账号。发现账号被盗用或异常，请立即联系平台处理。

## 四、任务与作品规范

1. 领取推广任务后，你应在规定时间内按要求完成内容发布并在平台回填作品链接。
2. 你提交的作品须为原创或已获得合法授权，不得抄袭、搬运、篡改他人作品，不得含有违法违规、虚假宣传内容，不得违反知乎等内容平台的社区规范。
3. 作品须与关键词主题相关，审核不通过的作品可修改后重新提交。
4. 因作品违规被内容平台处罚（限流、删除、封号等）的，相关责任与损失由你自行承担；情节严重的，平台有权终止合作并冻结未结算收益。

## 五、收益与结算

1. 收益以平台与合作方核对后的报表数据为准，按你所属团队适用的单价规则计算。
2. 报表核对完成并由平台财务确认开放后，你可申请提现；提现申请经审核通过后由平台通过线下渠道付款。
3. 你应确保提现收款信息真实、准确、完整，因信息错误导致的付款失败或损失由你自行承担。
4. 收益涉及的个人所得税等税费，按国家法律法规由你自行申报或由平台依法代扣代缴。
5. 邀请好友奖励按平台当期公布的规则发放，平台保留对作弊、自邀等异常行为取消奖励的权利。

## 六、禁止行为

你不得利用本平台：1. 从事任何违法违规活动；2. 恶意注册、刷量、作弊、虚构交易套取奖励；3. 攻击、破坏平台系统或干扰平台正常运行；4. 泄露平台任务价格、渠道数据等商业信息；5. 冒用他人身份或侵犯他人合法权益。违反上述约定的，平台有权限制功能、冻结收益、终止服务并保留追究法律责任的权利。

## 七、服务变更与终止

1. 平台可因业务调整、系统维护等原因暂停或调整部分服务，并尽可能提前通知。
2. 你可随时停止使用并联系平台注销账号；账号注销后，未结算收益按平台规则处理。
3. 你违反本协议的，平台有权终止向你提供服务。

## 八、责任限制

1. 平台按「现状」提供服务，因不可抗力、网络故障、第三方平台（如知乎）规则变化导致的服务中断或数据差异，平台不承担超出其合理控制范围的责任。
2. 你与内容平台之间的权利义务由你与该平台另行约定，平台不对内容平台的处理结果承担责任。

## 九、法律适用与争议解决

本协议的订立、履行与解释适用中华人民共和国法律。因本协议产生的争议，双方应友好协商解决；协商不成的，提交平台运营方所在地有管辖权的人民法院处理。
