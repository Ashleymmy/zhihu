# TIMO（提墨画江湖）隐私协议

最新修改日期：2026年10月3日

版本生效日期：2026年10月3日

本服务由芜湖云途文化传媒有限公司运营。本协议适用于 TIMO（提墨画江湖）网站及微信小程序的账号、项目协作、作品登记、业务数据和结算管理服务。我们按实际功能处理信息，不因您阅读本协议而自动取得尚未使用功能的授权。

## 一、我们处理哪些信息

**注册与登录：**使用平台账号和密码注册、登录，密码以不可逆散列保存，昵称可以选填或修改。网站和小程序使用同一平台账号。账号密码注册、登录不要求先验证手机号，也不会自动绑定微信。

**微信访问与主动绑定：**微信云开发向服务端提供当前小程序的用户标识 OpenID 和小程序标识，用于识别请求来源、会话安全和您主动选择的微信登录或绑定。首次绑定按页面提示验证平台密码和手机号，已有绑定支持微信快捷登录。我们不要求微信密码，不获取微信好友列表，不将微信标识用于无关推广或跨小程序画像。平台昵称由您输入，当前不调用微信头像、性别、地区或通讯录获取能力。

**可选手机号验证：**在“我的 → 个人信息 → 手机号验证”中，您可提供手机号码、平台密码和短信验证码，用于验证号码持有权及您选择的短信登录、微信绑定等安全功能。不验证手机号不影响平台账号密码登录。验证码只用于本次验证，具有有效期和发送频率限制，不公开展示或写入普通业务日志。

**备用联系方式：**您可自愿填写用于业务核对或紧急联系的备用联系方式，也可在同一页面清空。请勿提交与服务无关的信息。

**项目协作：**您领取或创建关键词、登记作品、管理成员或处理报表时，我们处理对应的项目、计划、关键词、作品链接、发布账号名称、发布时间、审核结果、邀请来源、团队归属和操作记录。邀请链接或分享卡片可携带邀请信息，团长邀请的达人建立团队归属，无邀请入口也可注册为平台管理的独立达人。邀请归属不代表授权公开联系方式。

**收益与付款：**为核对真实业务报酬，我们处理官方报表、作品归因、约定单价、账单和提现记录。您主动申请提现时提供收款人、银行或支付渠道及收款账号；财务人员实际付款后登记凭据。我们不要求银行卡密码或支付密码。手机号验证不等同于法定实名认证。

**安全与运行：**为保护账号及排查错误，记录必要的请求时间、接口、结果、耗时、客户端版本、环境、IP、客户端标识及会话信息。网站设备限制与小程序会话独立。日志避免保存密码、验证码、令牌和完整微信标识。

## 二、双端共享和使用范围

网站和小程序是同一运营者的服务入口，共用账号和业务数据库。一端修改资料、登记作品或进行业务操作后，另一端在权限范围内读取更新，不需再次导入账号。

项目、作品、团队和结算信息仅向本人及履行业务职责必需的团长、运营和财务人员展示，执行角色和项目权限控制。手机号、微信标识及收款信息不因加入团队而向所有成员公开。微信标识用于本小程序身份与安全处理，不用于无关业务的用户关系分析。

我们不出售个人信息，不仅为营销目的将其提供给其他主体。超出上述目的处理时，将另行告知并在需要时取得同意。

## 三、服务提供方与内容安全

**腾讯微信及微信云开发：**提供小程序运行、云函数和微信身份能力。云函数经 HTTPS 将请求传至平台服务端。对昵称、关键词、作品账号名称及其他需展示的文字，调用微信内容安全接口，提交必要文字、当前小程序 OpenID 和场景信息。密码、验证码、手机号及收款账号不作为检测文本提交。未通过或未完成检测的内容不会继续提交；您可修改重试或联系运营者申诉。

**阿里云及通信运营商：**阿里云提供境内服务器、数据库运行环境和短信发送服务。您主动获取验证码时，向阿里云短信服务及相关运营商提供接收号码和验证码模板参数，用于发送验证短信。

**业务合作方（如知乎）：**您主动提交作品或使用项目功能时，向对应合作方传送必要的作品链接、关键词、发布账号、分类、时间等业务信息，获取审核结果及订单报表，范围以所参与项目和页面提示为准。

当前小程序未接入广告、个性化推送、美颜、位置采集、通讯录、通话记录或设备应用列表 SDK，不会以这些未使用功能的名义额外收集信息。

## 四、存储与保护

业务数据库部署在本平台中国境内的阿里云服务器，微信云函数在微信云开发环境处理请求。当前服务不主动安排个人信息跨境传输。

我们采取 HTTPS、密码散列、会话撤销、权限控制、敏感操作验证及必要审计保护信息。仅在服务所需期限内保存；交易结算、履约、争议处理及依法应保留的记录按对应要求限制使用和保存。备份不用于恢复已注销账号或日常业务处理，在备份轮换时清理；依法需留存的部分仅用于相应目的。

## 五、您的权利与注销

您可在“我的 → 个人信息”查看账号、手机验证和微信绑定状态，修改昵称或清空备用联系方式。需更正其他信息、解除绑定、获取副本或提出删除请求时，可联系下述邮箱核验处理。

**注销入口为“我的 → 帮助与隐私 → 注销账号”，个人信息页也提供入口。**系统展示未结清款项、进行中的业务、成员或项目移交等待处理事项；无阻碍时，输入平台密码、勾选确认并在弹窗再次确认后完成注销。存在待处理事项时不会自动注销或放弃余额，请处理后重试，或联系我们协助。

**注销针对网站和小程序共用账号，两端同时失效，无法恢复。**关闭时清除原登录账号、密码凭据、昵称、手机号、邮箱、备用联系方式、微信绑定、会话和临时上传资料，使邀请链接失效。为保持交易、履约和财务审计可追溯性，必要结算凭证、业务记录及内部关联编号不一并物理删除，按适用要求保留并限制使用。注销不抹除未履行的法定义务。

服务面向具备相应民事行为能力的业务合作人员，不以未成年人为服务对象。请勿擅自提交未成年人信息。若认为我们不当处理了未成年人信息，请联系运营者核查。
